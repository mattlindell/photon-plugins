# Leadership

Skills for managing a team and working across an organization. Each follows one shape: north-star principles, a branch router (design-a-system vs. a tactical "do this now" path), and reference files (`INTAKE`, `WORKFLOW`, `TEMPLATES`, `CHECKLISTS`, `RUBRIC`).

## Model-invoked

Carry trigger phrasing so the model can reach for them on its own. Start with the router if you're not sure.

- **[leadership](./leadership/SKILL.md)** — Router over the leadership skills. Describe your situation and it points you to the right one.
- **[running-effective-1-1s](./running-effective-1-1s/SKILL.md)** — Design a 1:1 operating system or prep a specific 1:1, skip-level, or career conversation.
- **[having-difficult-conversations](./having-difficult-conversations/SKILL.md)** — Prep and deliver feedback, performance, promotion-denial, or (HR-gated) layoff/termination conversations.
- **[managing-timelines](./managing-timelines/SKILL.md)** — Turn a deadline into a plan or rescue a slipping one — milestones, RAG cadence, scope/change control.
- **[managing-up](./managing-up/SKILL.md)** — Manage your boss: weekly updates, escalations and asks, boundary resets, exec influence.
- **[running-effective-meetings](./running-effective-meetings/SKILL.md)** — Prep or run a specific meeting — decision/strategic/operational formats and meeting hygiene.
- **[cross-functional-collaboration](./cross-functional-collaboration/SKILL.md)** — Work across teams: defuse a conflict, unblock a dependency, or set decision rights.
