# Offsite Playbook (Heuristics)

Topic-keyed heuristics, defaults, and anti-patterns for the branches in `../SKILL.md`. Adjust every default to your context.

## Anti-patterns (catch yourself)

- **The vibes offsite.** If the goal is "feel more aligned" with no artifacts, you'll get a nice trip and no change. Name 3–7 concrete outputs first.
- **Death by presentation.** Eight hours of talks is a conference, not an offsite. Aim for ~60% interactive co-creation.
- **Workshop as trust repair.** A storytelling exercise won't fix conflict or resentment — it papers over it. Repair trust separately, then gather.
- **Laptops open during co-creation.** Multitasking kills the deep work you flew everyone in for. Enforce laptops down; use a single scribe.
- **Strategy before connection.** Diving into hard tradeoffs with a cold room produces defensive debate. Build connection first.
- **Monday amnesia.** No memory artifact, no owners, no checkpoint means the alignment is gone by the next standup. Close the loop within 24–48 hours.

## Core design rules

1. **Create space:** remove people from the day-to-day, or simulate it with laptops-down rules and timeboxed comms breaks.
2. **Imprint memory:** end with a tangible artifact (1-page narrative, principles, photos of boards + summary) plus a follow-up checkpoint.
3. **Fix the real problem:** if trust/conflict is the blocker, don't hide behind a soft-skills workshop.
4. **Defrag the day:** for strategic work, prefer physical collaboration (whiteboards, stickies) and ban multitasking.
5. **Connection before strategy:** start with human connection so later disagreement is productive.
6. **Make logistics frictionless:** remote-first teams benefit from repeatable bursts with low ops overhead.

## Session pattern library (pick 3–6)

- **Context alignment (30–60 min):** shared "current state" + constraints. Silent read of the pre-read, then structured Q&A.
- **North Star + success definition (45–75 min):** success measures + non-goals. Small-group draft → merge → vote.
- **Strategy bets / priorities (90–150 min):** 3–5 bets with rationale + anti-bets. Diverge (ideas) → converge (criteria + vote) → commit (owners).
- **Decision principles (45–60 min):** 5–9 principles for making tradeoffs. Examples → extract principles → test against scenarios.
- **Working agreements (45–75 min):** explicit norms for decisions, comms, escalation. Start/stop/continue + negotiation.
- **Skill share / internal expert workshop (45–90 min):** a shared method + template. Internal expert teaches; teams practice on real work.
- **Retro + reset (45–90 min):** top 3 fixes + owners + timeline. Retro prompts + dot voting.

## Facilitation defaults

- **Laptops down** during co-creation blocks; if docs are needed, use a single scribe pattern.
- Use **physical artifacts** where possible: whiteboards, stickies, printed agendas.
- Build in breaks: 10 min every 60–90 min, plus a longer mid-day break.
- Keep a **parking lot** for off-topic items; assign owners during the close.
- **Decision capture:** every decision records (a) statement, (b) rationale, (c) tradeoffs, (d) owner, (e) review trigger/date.

## Handling tension safely

If you detect trust debt or conflict:
- Keep group activities bounded — focus on observable behaviors and working agreements.
- Avoid forced-vulnerability exercises.
- If conflict is severe or carries HR/legal risk, escalate to leadership/HR and redesign the offsite around safer topics.

## Burst cadence (remote-first)

Choose bursts when you're mostly remote and need periodic high-velocity creative work plus relationship reinforcement, with a repeatable, predictable pattern.

Defaults:
- **Frequency:** quarterly (or semi-annual for smaller teams).
- **Length:** 2 days (travel permitting).
- **Day 1:** connection + context + divergence.
- **Day 2:** convergence + decisions + action plan + comms.

## Follow-through (anti-amnesia)

Within 24–48 hours: send the decision/action summary, publish the memory artifact, and schedule the first checkpoint (2–3 weeks out).
