# Running Effective 1:1s

## The 1:1 is the report's meeting

Anchor every choice below to four ideas:

- **The report's meeting, not yours.** They set most of the agenda; you listen more than you talk. If you're using more than half the airtime, you're doing it wrong.
- **Coach, don't bottleneck.** Ask before you answer. Go directive only for risk, safety, policy, or genuinely time-critical calls.
- **Status has another home.** Project and sprint status belongs in an async doc or a team ritual, not here. A 1:1 that became a status readout is a 1:1 that stopped working.
- **Don't skip them.** Canceling a 1:1 to "save time" is the most expensive meeting you'll ever cancel. Reschedule instead of dropping.

## When to use / not

Use to stand up or repair a 1:1 system, prep a specific upcoming 1:1, or run a career or skip-level conversation.

Do **not** use for: a performance-improvement plan, investigation, or termination — route to HR / your company process (the **having-difficult-conversations** skill prepares the conversation itself); a project-status cadence — that's a team ritual; or an active safety or mental-health crisis — follow company policy and point to professional resources.

## Branch A — Build the 1:1 operating system

1. **Separate the channels.** Map what goes where: status → async doc / team ritual; 1:1 → coaching, feedback, career, wellbeing, sensitive blockers, relationship.
   **Done when:** status has an explicit non-1:1 home.
2. **Set the cadence (barbell).** Tailor by relationship — new, stable, senior/independent, under-stress — and add a fast path for urgent topics. Heuristics: [references/WORKFLOW.md](references/WORKFLOW.md).
   **Done when:** every report has a cadence and a way to escalate within ~48h.
3. **Stand up the shared doc.** One doc per report; both sides add agenda items beforehand; every meeting ends with owner + due date. Template: [references/TEMPLATES.md](references/TEMPLATES.md).
   **Done when:** the doc has agenda, a running topic backlog, notes, and an action tracker.
4. **Adopt the coaching stance.** Install the question bank and the directive-exception list so the default move is a question.
   **Done when:** exceptions for going directive (risk/safety/policy/time) are written down.
5. **Schedule the career sequence.** Put the three sessions from Branch C on the calendar as dedicated time, not squeezed into a weekly.
   **Done when:** the sequence has a first date booked.
6. **Add wellbeing + special-situation playbooks.** A lightweight energy/joy check-in with clear boundaries, plus ready-to-run post-crisis and skip-level playbooks.
   **Done when:** boundaries and escalation paths are documented.
7. **Quality gate + rollout.** Pass [references/CHECKLISTS.md](references/CHECKLISTS.md), score with [references/RUBRIC.md](references/RUBRIC.md), propose a 2–4 week pilot, and close with **Risks / Open questions / Next steps**.

Deliverable: a **1:1 Operating System Pack** — channels map, cadence plan, shared-doc template, coaching toolkit, career plan, and wellbeing + special-situation playbooks.

## Branch B — Prep a specific 1:1

The weekly workhorse. Produce a prep sheet, not a system.

1. **Pull the thread.** Review last meeting's open action items, the topic backlog, and recent signals — wins, misses, energy.
2. **Build the agenda, report first.** Their topics lead; hold yourself to ≤2 items. Agenda menu and prep sheet: [references/TEMPLATES.md](references/TEMPLATES.md).
3. **Frame any feedback** as observation → impact → request — a specific behavior, never a label.
4. **Plan one coaching thread** and an energy/joy read to take.

**Done when:** a one-page agenda exists with the report's topics first, ≤2 of yours, any feedback framed as observation → impact → request, and a follow-up on last week's actions.

## Branch C — Career conversation

Run the three-session sequence — **Life Story → Future Dreams → Career Action Plan** — as dedicated 45–60 min sessions, distinct from tactical weeklies. Scripts and outputs: [references/TEMPLATES.md](references/TEMPLATES.md); facilitation notes: [references/WORKFLOW.md](references/WORKFLOW.md).

**Done when:** the report has 1–3 written growth bets tied to real projects, each with a checkpoint.

## Branch D — Skip-level

Clarify one purpose — signal-gathering, coaching, or unblocking, never bypassing the direct manager — pick 5–8 questions, and set the notes rule: share themes, not quotes or names. Template: [references/TEMPLATES.md](references/TEMPLATES.md).

**Done when:** the purpose is explicit and note-handling protects the manager relationship.

## Branch E — Post-crisis listening 1:1

After a hard event — layoff, reorg, incident — run a listening-first session: invite thoughts and feelings, reflect back what you hear, and resist status or problem-solving. Template: [references/TEMPLATES.md](references/TEMPLATES.md).

**Done when:** the report has been heard and any actions are limited to support and clarity, not execution.

## Examples

- *"My 1:1s have turned into status readouts — redesign them."* → **Branch A**: channels map that moves status async, barbell cadence, coaching toolkit.
- *"I have a 1:1 with a struggling report tomorrow."* → **Branch B**: prepped agenda, one feedback item as observation → impact → request, an energy read to take.
- *"I need to document poor performance and start a PIP."* → out of scope: route to HR; offer to prep the conversation via the **having-difficult-conversations** skill.
