# Linear IDs (local, gitignored)

Coordinates and connection preferences for this repo's Linear workspace. This file is not committed. It keeps workspace identifiers out of the repo and lets each person record how their own machine reaches Linear.

## Placeholder resolution

`issue-tracker.md` names the team and project only by placeholder. This file is the only place they resolve.

| Placeholder | Value |
| --- | --- |
| `<TEAM>` | `<team key>` |
| `<PROJECT>` | `<project name>` |

## Connection preference

The committed `issue-tracker.md` doesn't name a connection method. Write this machine's preference here, for example which CLI or MCP server to try first and what to fall back to. Leave it empty to use whatever access the runner has.

## Raw IDs

Optional. Record UUIDs for the team, project, statuses, or labels here when two things share a name or a lookup is worth skipping.
