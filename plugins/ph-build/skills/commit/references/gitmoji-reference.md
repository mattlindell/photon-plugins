# Gitmoji Reference

Curated emoji set for conventional commits. All entries map to standard conventional commit types.

## Core

| Emoji | Type     | When to use                            |
| ----- | -------- | -------------------------------------- |
| ✨    | feat     | New feature or functionality           |
| 🐛    | fix      | Bug fix                                |
| ♻️    | refactor | Code restructuring, no behavior change |
| 📝    | docs     | Documentation changes                  |
| ✅    | test     | Adding or updating tests               |
| 🎨    | style    | Code formatting, structure improvement |
| ⚡️    | perf     | Performance improvement                |
| 🔧    | chore    | Config, tooling, maintenance           |

## Situational

| Emoji | Type     | When to use              |
| ----- | -------- | ------------------------ |
| 🚀    | ci       | CI/CD pipeline changes   |
| ➕    | chore    | Add a dependency         |
| ➖    | chore    | Remove a dependency      |
| 🔒️    | fix      | Security fix             |
| 💥    | feat     | Breaking change          |
| ⏪️    | revert   | Revert a previous commit |
| 🔥    | chore    | Remove code or files     |
| 🚚    | refactor | Move or rename resources |

## Occasional

| Emoji | Type  | When to use                                        |
| ----- | ----- | -------------------------------------------------- |
| 🗃️    | chore | Database schema or seed changes                    |
| ♿️    | feat  | Accessibility improvement                          |
| 🌐    | feat  | Internationalization                               |
| 🚧    | chore | Work in progress (incomplete, not for main branch) |
| 🎉    | chore | Initial commit / begin project                     |
