# Operator tools

**Membership test:** you invoke this skill directly. It acts on the conversation
or on the agent system, never on a work product. Nothing else references it, so
none of these is a dependency of anything.

All nine are user-invoked (`disable-model-invocation: true`) — type
`/ph-lib:<name>`.

- `automate-me`
- `bro`
- `caveman`
- `handoff`
- `recall`
- `reflect`
- `teach`
- `wait-what`
- `what-did-i-get-done`

Descriptions live in the [plugin README](../../README.md) — one place, so they
cannot drift.
